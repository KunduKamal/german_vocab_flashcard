# 🇩🇪 German Vocabulary Flashcards (A1-A2 Level) 🇧🇩

A web-based, interactive flashcard application designed to help Bengali speakers learn over 700 essential German words for the A1-A2 levels. This project is built with vanilla HTML, CSS, and JavaScript, focusing on a clean user interface and effective learning tools.

## 🚀 Live Demo

You can access and use the live application here:

**[https://kundukamal.github.io/german_vocab_flashcard/german_fl.html](https://kundukamal.github.io/german_vocab_flashcard/german_fl.html)**

## 📚 About The Project

Learning a new language requires consistent practice with vocabulary. This tool aims to make that process easier and more engaging. It provides a digital deck of flashcards categorized by topics, complete with German articles, pronunciation, and practical example sentences in both German and Bengali.

## ✨ Features

* **Extensive Vocabulary:** Over 700+ words covering essential A1-A2 topics.
* **Categorized Learning:** Words are grouped into topics like Family, Food, Body, Clothing, and more.
* **Multiple Learning Modes:**
    * **Sequential:** Learn words in a structured order.
    * **Random:** Shuffle the deck for a surprise challenge.
    * **Difficult Words:** Focus only on the words you've marked as "hard".
* **Interactive Cards:** Simply click on a card to flip it and reveal the meaning, example, and pronunciation.
* **Progress Tracking:** Mark words as "Easy", "Medium", or "Hard". Your progress is saved in your browser's local storage.
* **Helpful Examples:** Each word comes with an example sentence in both German and Bengali to provide context.
* **Clean & Responsive Design:** A modern, user-friendly interface that works on both desktop and mobile devices.

## 💻 Tech Stack

This project was built using only fundamental web technologies:

* **HTML5:** For the structure of the application.
* **CSS3:** For styling and layout, including flexbox and gradients.
* **Vanilla JavaScript:** For all the logic, including card manipulation, progress tracking, and interactivity.
